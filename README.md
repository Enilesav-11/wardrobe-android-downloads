Download the APK on your Android phone. If prompted, allow your browser or file manager to install unknown apps, then open the APK and tap Install. The SHA-256 is listed above for verification.

## Preview limitations

This preview has not been installed or startup-tested on a real device. Supabase Free can pause after inactivity. Public email signup needs a production SMTP sender. AI virtual try-on is not configured; the app provides its labeled outfit collage. Privacy/support pages are not published yet.

The source repository remains private. This repository contains Android release binaries only. See [all releases](https://github.com/Enilesav-11/wardrobe-android-downloads/releases).
